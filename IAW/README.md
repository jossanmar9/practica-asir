# IAW · Preparació de l'examen UT1 i UT2

**100 casos de raonament, sense solucions**, organitzats en 10 blocs de 10 casos. El format segueix les indicacions de la professora: interpretar situacions i fragments, localitzar el component implicat, proposar canvis xicotets i explicar com verificar-los. **No cal VS Code ni executar codi.**

| Unitat | Blocs | Casos |
|---|---:|---:|
| UT1 · Entorn d'implantació web | 5 | 50 |
| UT2 · Programació web amb PHP | 5 | 50 |

Cada cas té tres apartats (0,30 + 0,40 + 0,30 punts), com els exemples del PDF facilitat a classe. És una **pauta de pràctica**, no una predicció literal de l'examen. Les preguntes són noves i no copien els exemples resolts.

## Com utilitzar-los

1. Llig un cas i respon en el mateix `.md`, sense consultar les solucions de classe.
2. Identifica el **què passa**, el **canvi mínim** i la **prova/evidència**.
3. Marca el teu progrés en `seguiment.csv` i envia'm els casos resolts per a corregir-los.
4. Repetix els casos que no arriben a 0,8/1 amb una variant diferent.
